# boward-research
a demo app to familiarize with tools

React + TypeScript (Vite) frontend, Fastify + TypeScript API, PostgreSQL/PostGIS, Drizzle ORM, Better Auth.
Everything runs in Docker, so the only thing you need installed is Docker Desktop.

## Tech stack

### Languages

- **TypeScript**: all app code, in both `api/` and `web/`. `tsc` only type-checks (`npm run typecheck`); nothing is compiled to disk.
- **TSX**: React components in `web/src/*.tsx`.
- **SQL**: migrations in `api/drizzle/`, generated by drizzle-kit from `api/src/schema.ts`.
- **CSS**: one plain stylesheet, `web/src/styles.css` (no CSS framework).
- **HTML**: `web/index.html`, the single page Vite serves.

### Runtime and infrastructure

- **Node.js 24** (`node:24-alpine` image): runs the API and the Vite dev server.
- **npm workspaces**: one root `package.json` and `package-lock.json`, with `api` and `web` as workspaces.
- **Docker / Docker Compose**: three services, `db`, `api` and `web`. With `--watch`, edits to `src/` are synced into the containers and a `package.json` change rebuilds the image.
- **PostgreSQL 17 + PostGIS 3.5** (`postgis/postgis:17-3.5` image): the database, exposed on host port 5433. PostGIS adds geographic types and queries for location/map features; no table uses it yet.

### API (`api/`)

| Library | What it's for |
| --- | --- |
| Fastify | HTTP server and routes (`src/server.ts`) |
| Drizzle ORM | Typed SQL query builder; tables are defined in `src/schema.ts` |
| pg (node-postgres) | Postgres driver that Drizzle uses underneath |
| Better Auth | Email/password sign-up, sign-in and sessions, served at `/api/auth/*` and stored through its Drizzle adapter |
| drizzle-kit (dev) | Generates migrations from the schema (`npm run db:generate -w api`) and applies them (`db:migrate`, run on container start) |
| tsx (dev) | Runs the TypeScript directly and restarts on changes (`tsx watch`) |
| TypeScript, @types/node, @types/pg (dev) | Type checking |

### Web (`web/`)

| Library | What it's for |
| --- | --- |
| React + React DOM | UI |
| Better Auth (React client) | `createAuthClient` from `better-auth/react`, for sign-in, sign-out and the current session |
| Vite | Dev server with hot reload; proxies `/api` to the API container so the auth cookie stays same-origin |
| @vitejs/plugin-react (dev) | React support and fast refresh in Vite |
| TypeScript, @types/react, @types/react-dom (dev) | Type checking |

## Run it

```sh
docker compose up --watch
go to
 http://localhost:5173

 close:
 docker compose down -v
 docker compose restart api
```
